Appendix C

Glossary

TermMeaning
A2AAgent2Agent protocol: how agents discover each other and hand off work.
Agent 365Microsoft’s agent control plane for its own estate, with Microsoft Entra Agent ID for agent identities.
Agent BrokerMuleSoft Agent Fabric capability that routes multi-step work across agents and tools, with guided determinism for fixed hand-off rules.
Agent Kill SwitchMuleSoft Agent Fabric capability that stops agent activity quickly.
Agent lifecycleThe stages an agent passes through: proposal, registration and onboarding, evaluation, promotion, monitoring, recertification and retirement.
Agent Registry and ScannersThe single source of truth for agents, APIs and MCP tools, with automatic discovery across ecosystems.
Agent sponsorThe named person accountable for one agent from registration to retirement, including recertification and the first call in an incident.
Agent VisualizerMuleSoft Agent Fabric capability that shows how agents, tools and systems interact, with confidence, bottleneck and hallucination-risk signals.
AI GatewayThe one policy point for LLM and MCP traffic: routing, token-based rate limits, masking, spend attribution and logging.
Amazon Bedrock AgentCoreAWS services for running agents: a runtime, memory, a gateway that connects MCP servers, identity and observability.
Audit modeRunning a new policy so that it records what it would block before it enforces anything.
Autonomy tierThe level of authority an agent has (assisted, supervised, autonomous, multi-agent) and the controls each level requires.
Bound approvalAn approval tied to one exact action and valid for a limited time. The gateway refuses the action if either has changed.
Control planeThe governed layer between everything that consumes intelligence and everything that provides it.
Cumulative valueThe sum of each milestone’s run rate over the months it was in force.
Data contractThe schema, meaning and quality thresholds that an MCP tool guarantees.
FOCUSThe FinOps Open Cost and Usage Specification: a common format for cloud and AI billing data.
Golden recordThe trusted, de-duplicated master record for an entity such as a client, worker or asset.
InformaticaThe data foundation for AI agents: master data, data quality, catalog and governance, with data services exposed to agents through MCP servers.
Leading indicatorAn early signal, defined the same way by every team, that moves within weeks and predicts a scorecard metric.
LLM GovernanceMuleSoft Agent Fabric capability that gives central visibility into token usage, cost and data flows for third-party models.
MCPModel Context Protocol: how agents reach tools and data.
MCP BridgeMuleSoft capability that turns existing APIs into governed MCP tools.
MuleSoft Agent FabricThe control plane that registers, governs, orchestrates and observes agents and MCP endpoints, whatever platform built them.
Multidomain MDMInformatica master data management for domains such as customers, suppliers, products and assets.
North starThe vendor-neutral target reference architecture that every decision is measured against.
Omni GatewayMuleSoft gateway that applies policies to APIs, A2A and agent traffic, including custom policies built with the Policy Development Kit.
On-behalf-of tokenA delegated token that lets an agent act for a specific person with narrowed scopes.
OWASP Top 10 for Agentic ApplicationsThe OWASP list of ten agentic security risks, ASI01 to ASI10, from agent goal hijack to rogue agents.
Policy Development Kit (PDK)The kit for writing custom Omni Gateway policies in Rust, compiled to WebAssembly.
Quick winA first slice of a use case that shows measurable value within about 90 days, runs read-only or propose-only, and leaves a reusable foundation behind.
RecertificationA scheduled review in which an agent’s sponsor confirms that it is still needed, in the right tier and with the right permissions.
Run rateAnnualized value being delivered at a milestone.
Runtime FabricCustomer-managed MuleSoft runtime for running gateways and MCP servers inside the client’s own environment. CloudHub is the MuleSoft-managed alternative.
Signed agent cardAn A2A agent card signed by its issuer, so another agent can verify who it is dealing with.
System of recordThe authoritative application for a business object, such as SAP S/4HANA for projects and billing.
Takeover runbookThe plan for who takes over an agent’s open work when it is stopped, with what information, and how the process continues.
Trajectory evaluationJudging an agent by the tools it chose and the order it used them in, as well as by its final answer.
Trusted Agent IdentityMuleSoft Agent Fabric capability that lets agents act with a specific user’s identity and authorization, with mobile approval for high-risk steps.
Work modeWhether a step is human-led, AI-assisted or AI-led, decided by asking whether AI could do it and whether it should.
Zero trustA security model in which every actor is authenticated and every call is authorized for the specific task. Nothing is trusted because of where it sits on the network.
