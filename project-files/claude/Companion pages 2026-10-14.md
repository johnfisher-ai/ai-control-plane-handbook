- **Repair prompt fixed (October 15, 2026; pushed as `e90f108`, and John downloaded and confirmed).** John found that PowerPoint asked to repair each download. Cause: when the slide text was edited (the AI-tell pass), the script that rebuilt the text runs left two paragraph-property elements (`a:pPr`) next to each other at the start of 63 edited paragraphs; pptxgenjs writes one before each run, which PowerPoint tolerates, but adjacent duplicates make it repair the file. The XSD validator does not catch this. Tested in John's PowerPoint (Mac): the original public deck opens cleanly, the edited deck asked for repair, and the deck with the duplicates removed (`fix_ppr.py`, giving `build/deck_fixed.pptx`) opens cleanly, as do the rebuilt one-slide files. The slides render exactly as before, so the site images did not change. The same fix was applied to the edited client deck (`build/clientdeck_fixed.pptx`) for any future use.
- **Notes page layout.** In Notes Page view (and printed notes) the deck's notes text ran off the page, because the generator's notes placeholders carry no position of their own; this was already true of the original deck. The downloads now give the notes text and page number a position on the page, so the text wraps and prints. The slide picture still does not appear in Notes Page view in PowerPoint, as in the original deck.
- **Font on a Mac without Plus Jakarta Sans.** In John's PowerPoint the slides show in Calibri rather than the embedded Plus Jakarta Sans (the original deck behaves the same). Calibri is narrower, so nothing overflows. Installing Plus Jakarta Sans (free, SIL Open Font License) shows the slides as on the site. Not yet investigated further.
