Overview

Executive summary

Enterprise infrastructure was built to host applications, store data and process transactions. Agentic AI changes the job. As models, agents and AI workloads spread across clouds, applications, devices and the edge, infrastructure must coordinate who acts, with which data, on which model, where, and within what limits. The answer is an enterprise control plane: a governed, intelligent layer that mediates decisions across systems.1

The urgency is practical. Organizations already run an average of 12 agents, a number expected to grow by two-thirds within two years, and half of those agents operate in silos.2 Without a control plane, each team wires its own models, keys and guardrails, and the enterprise inherits fragmented policy, invisible cost, vendor lock-in and no fallback when a provider fails.

Key takeaways

  • The control plane is the new infrastructure advantage. Advantage will come from a governed system that decides which model runs which task under which constraints, not from any single model.
  • It rests on three capabilities. Architecture exposes enterprise capabilities securely; orchestration coordinates models, agents, workloads and decisions; trust, security and resilience verify every actor and output continuously.
  • Choose the paradigm before the platform. Embedded, dedicated and hybrid/federated patterns carry different trade-offs. Most large multi-vendor enterprises converge on central policy with distributed execution.
  • MuleSoft can realize both halves. Its API-led connectivity unlocks enterprise applications as governed APIs and MCP tools. Agent Fabric discovers, governs, orchestrates and meters agents from any vendor.
  • Build foundations in phases over the next 12–24 months, with value in every phase. Inventory agents, route all model and tool traffic through one gateway, tier autonomy, give agents their own identities, and start post-quantum migration ahead of the 2030–2031 federal deadlines, while each phase puts a slice of a real use case into production.

Decisions requested in the next 90 days

  1. Name an owner. One accountable executive and a governance council spanning architecture, security, data and the business, covering agents, models and AI spend.
  2. Fund Phase 1. A 90-day program to inventory every agent, route all LLM and MCP traffic through a single AI gateway, baseline cost and risk, and put the first use-case slice into production with its value measured.
  3. Set the standard. Make API-led connectivity, MCP and A2A enterprise policy, and require every agent, whatever platform built it, to be registered and routed through the control plane.
